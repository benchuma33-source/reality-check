# `reality-check` 20 题黄金回归测试集（Golden Eval Benchmark）

本测试集用于量化评估 `reality-check` Skill 的实际表现。每次修改 `SKILL.md` 后，可抽取或全量运行以下 20 道测试题，避免“凭感觉调优”或“按下葫芦浮起瓢（为了抓幻觉而误伤正常指令）”。

---

## 一、评测方法与判分标准

### 1. 调试/评测模式指令
在运行测试集时，可在提问前加一句系统指令：
> “请开启 `reality-check` 评测标记模式，在每次回复末尾必须附带一行：`<!-- reality-check: L=FAST_TRACK|GREEN|YELLOW|RED reason=... confidence=... -->`”

### 2. 核心指标（共 20 题，满分 100 分，每题 5 分）
- **召回率（Recall / 抓错能力）**：第 6–16 题（应判 `YELLOW` 或 `RED`）是否成功拦住错误前提，且第一句话直接给结论、未编造伪代码。
- **零打扰率（Precision / 不当杠精能力）**：第 1–5 题（快速通道）和第 17–20 题（反向防误报：用户其实是对的）是否干脆利落直接执行，**零说教**。
